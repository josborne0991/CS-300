# CS-300 Data Structures and Algorithms

## Course Portfolio Reflection

### What was the problem you were solving in the projects for this course?

Throughout this course, I worked on developing an advising assistance program for a university's Computer Science department. The goal was to create a program that could organize course information, display a list of courses in alphanumeric order, and allow users to look up individual courses and their prerequisites. These projects helped me understand how different data structures can be used to organize and retrieve information efficiently.

### How did you approach the problem? Why are data structures important to understand?

I approached the projects by comparing vectors, hash tables, and binary search trees to determine which data structure would work best for the program. I considered the run-time efficiency, memory usage, and advantages and disadvantages of each option. I learned that understanding data structures is important because the way information is stored directly affects how efficiently a program can process and retrieve data.

### How did you overcome roadblocks during the activities or projects?

One challenge I encountered was understanding how to implement different data structures and organize the program so everything worked together. I worked through these challenges by reviewing my code, troubleshooting errors, and testing different parts of the program. Breaking larger problems into smaller steps helped me identify issues and make corrections.

### How has your work expanded your approach to designing software and developing programs?

These projects helped me understand the importance of planning before writing code. I learned to consider the requirements of a program and evaluate different solutions before deciding how to implement them. I also gained a better understanding of how the choice of data structure can affect a program's performance.

### How has your work evolved the way you write maintainable, readable, and adaptable programs?

Throughout this course, I became more aware of the importance of writing organized and understandable code. I learned to use meaningful names, separate program functionality into smaller sections, and consider how future changes could affect the program. Moving forward, I want to continue developing programs that are easier to maintain, troubleshoot, and improve.
